# JobSpri

Lean hiring platform foundation with Django + Next.js, compact UI, resume builder, recruiter dashboard, and roadmap-ready hooks for verification, history tracking, and Razorpay payments.

## Included in this commit
- Django foundation models, admin, auth APIs, public jobs APIs, recruiter APIs, resume APIs with 10 template placeholders.
- Next.js app-router scaffold for auth, jobs, job detail/apply, resume builder, recruiter dashboard.
- Environment template and docker-compose for local development.
